# React Native Wallpaper App

This is a simple React Native app that includes:

- Exactly **5 wallpapers**
- A **Dark Theme** toggle
- A **Night Mode** toggle
- A wallpaper preview and selection row

## Run with Expo

1. Create a new Expo app (or use an existing one)
2. Replace its `App.js` with `mobile-app/App.js`
3. Start the app:

```bash
npx expo start
```

> Note: The "Apply Wallpaper" button is a UI stub. Actually changing the phone wallpaper requires native modules and platform permissions.
